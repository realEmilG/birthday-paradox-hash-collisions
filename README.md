# birthday-paradox-hash-collisions
Experimental study of the Birthday Paradox and hash function collisions
The journey we have gone through began with explaining simple probability and the NOT complement rule and then movig toward the birthday paradox. A few Python similations was run, showing how quickly the probability of matching birthdays dramatically increases when we put together in a room not very large number of people. The next step continued withalong explaining the birthday attack connecting the bithday paradox with information security and we did accomplish the introduction to hash functions. Finally, a simple controllable hash function were shown and then collisions was demonstrated with experiments using different hash function lengths in bits.
