# birthday-paradox-hash-collisions
Experimental study of the Birthday Paradox and hash function collisions.
The journey we have gone through began with explaining simple probability and the NOT complement rule and then it was moved toward the birthday paradox. A few Python similations was run, showing how quickly the probability of matching birthdays dramatically increases when we put together in a room not very large number of people. On the next step the the current study continued with explaining the birthday attack and the connection between the bithday paradox with information security was revealed. Also it was made a simple explaning of what is a hash function. Finally, an incomplex controllable hash function were shown and then collisions was demonstrated with experiments using different hash function lengths in bits.
